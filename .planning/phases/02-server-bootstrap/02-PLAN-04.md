<read_first>

</read_first>

<action>
1. Verify the layout's `shouldUseServerBootstrap()` check — when it returns false, the existing layout renders without bootstrap.

2. Verify DataProvider's useEffect — when bootstrap is null or bootstrapped is false, it falls back to `loadData()`.
