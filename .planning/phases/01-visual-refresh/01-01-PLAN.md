### 2. Create StyleSeed pattern components (12 files)

**Files created**: `components/patterns/`  
**Action**: Create each pattern component following the StyleSeed `engine/DESIGN-LANGUAGE.md` rules exactly:

#### 2a. `stat-card.tsx`

#### 2b. `hero-card.tsx`

### 3. Upgrade animation motion tokens

**Files**: `components/animation/enhanced-motion.tsx`  
**Action**: Add StyleSeed motion token constants to `enhanced-motion.tsx`:

```tsx
// StyleSeed motion tokens (add to top of file)
export const MOTION_DURATION = {
  fast: 100,    // --duration-fast: hover, color changes
  normal: 200,  // --duration-normal: enter animations, expand
  slow: 350,    // --duration-slow: page transitions, spring
} as const

export const MOTION_EASE = {
  default: [0.4, 0, 0.2, 1] as const,
  spring: [0.22, 1, 0.36, 1] as const,
  entrance: [0.16, 1, 0.3, 1] as const,
  bounce: [0.68, -0.55, 0.265, 1.55] as const,
} as const

// Add new entrance variant (blur-in per StyleSeed pattern)
const BLUR_ENTRANCE: Variants = {
  hidden: { opacity: 0, y: 24, filter: "blur(12px)" },
  show: {
    opacity: 1,
    y: 0,
    filter: "blur(0px)",
    transition: { duration: 0.9, ease: MOTION_EASE.spring }
  }
}
```

Update `MotionSection` to use `MOTION_DURATION.normal` (200ms) instead of hardcoded `0.6`.  
Update `MotionStaggerItem` to use `BLUR_ENTRANCE` variant as an option (add `variant?: 'blur' | 'fade'` prop).  
Add `MotionPhrase` component for multi-line staggered text reveals (per Resend/Expo style).

**Acceptance criteria**:
- [ ] `MOTION_DURATION` and `MOTION_EASE` constants exported
- [ ] `MotionSection` uses `MOTION_DURATION.normal`
- [ ] `MotionStaggerItem` supports `variant="blur"` option
