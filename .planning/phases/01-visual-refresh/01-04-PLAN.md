## <tasks>

### 29. Anti-pattern sweep — hardcoded hex colors

**Action**: Run grep across all modified files to find hardcoded hex colors that should use CSS variables:

```bash
grep -rn "#[0-9a-fA-F]\{3,6\}" \
  app/\[locale\]/\(landing\)/ \
  app/\[locale\]/dashboard/ \
  app/\[locale\]/\(authentication\)/ \
  components/ \
  --include="*.tsx" | \
  grep -v "oklch\|hsl\|var(--\|CSS\|comment"
```

Fix any hex colors found that should use semantic tokens. Known exceptions (acceptable hardcoded values):
- Token definitions in CSS comments: `/* Precision Blue: oklch(0.55 0.22 264) */`
- Transparent elements: `transparent`
- Gradient endpoints in CSS definitions

**Acceptance criteria**:
- [ ] No hardcoded hex colors in TSX files (except gradient definitions)
- [ ] All color usage goes through CSS variables or Tailwind color tokens

### 30. Anti-pattern sweep — pure black

**Action**: Verify no `#000000`, `text-black`, `bg-black` in TSX files:

```bash
grep -rn "text-black\|bg-black\|#000000\|#000\|border-black" \
  app/ \
  components/ \
  --include="*.tsx"
```

Replace any found with `#2A2A2A` (strongest text) or appropriate semantic token.

**Acceptance criteria**:
- [ ] No pure black anywhere in TSX
- [ ] Strongest text color is `#2A2A2A` or `text-text-primary`

---

### 31. Anti-pattern sweep — key color overuse

**Action**: Verify key color is not overused per StyleSeed Rule 18:

```bash
grep -rn "bg-primary\|bg-brand" \
  app/\[locale\]/\(landing\)/ \
  components/ \
  --include="*.tsx" | \
  grep -v "bg-primary/\d\|bg-primary-\d\|bg-primary-\[\|opacity\|/10\|/15\|/20"
```

Fix any instances of key color being painted across large areas. Key color allowed: icon badges (10% opacity), progress fills, active/selected states, nav.

**Acceptance criteria**:
- [ ] No key color card backgrounds
- [ ] Key color only on small elements (badges, progress, active states)

---

### 32. Anti-pattern sweep — forbidden patterns

**Action**: Verify no forbidden StyleSeed patterns per Rule 18:

1. **Content outside cards**: Search for text/metrics directly on page background
```bash
grep -rn "space-y-6" app/\[locale\]/\(landing\)/page.tsx | head -20
```
Ensure all content inside `rounded-2xl p-6` cards.

2. **Dividers between sections**: Verify no `border-b` or `border-t` between section-level divs
```bash
grep -rn "border-t border-\|border-b border-" \
  app/\[locale\]/\(landing\)/ \
  --include="*.tsx" | \
  grep -v "shadow-card\|bg-card"
```
Only border-t dividers inside cards are allowed.

3. **CTA buttons inside card content**: Verify no "Order", "View More", "Sign Up" CTAs inside card content areas

4. **Card data density**: Verify no card has 5+ data items (Rule 21 max)

**Acceptance criteria**:
- [ ] All content inside cards (no orphaned text/metrics on page bg)
- [ ] No section-level dividers (border-t only inside cards)
- [ ] No CTAs inside card content areas
- [ ] No card with 5+ data items

### 37. Motion quality audit

**Action**: Verify all animations use StyleSeed motion tokens:

```bash
grep -rn "duration-\[0\.\|duration-600\|duration-800\|duration-1000\|duration-2000" \
  app/ \
  components/ \
  --include="*.tsx"
```

Also verify:
- All scroll-triggered animations use `viewport={{ once: true }}`
- All interactive elements respect `prefers-reduced-motion`
- Blur-in entrance for hero/key sections
- Stagger timing: 50-150ms per item
- No jarring animations

**Acceptance criteria**:
- [ ] No hardcoded unusual durations (600ms, 800ms, 1000ms+ in TSX)
- [ ] All scroll animations use `once: true`
- [ ] Reduced motion preference respected on all surfaces
- [ ] Stagger timing is 50-150ms
