═══════════════════════════════════════════════════════════════════════════════
  ROOT CAUSE CATEGORIES
═══════════════════════════════════════════════════════════════════════════════

1. CSS/STYLING ISSUES (40% likelihood)
   ├─ Tailwind CSS not generating output files
   ├─ CSS files 0 bytes or missing
   ├─ Design tokens not defined in styles/tokens.css
   ├─ Inline styles overriding theme colors
   └─ Dark mode forced with dark text on dark background

2. JAVASCRIPT RENDERING ERRORS (30% likelihood)
   ├─ Import failures (missing modules, wrong paths)
   ├─ Hydration mismatch (server vs client render difference)
   ├─ Async component failures (getI18n() failing)
   ├─ Params not awaited (Next.js 16 requirement)
   └─ Unhandled errors in HomeContent component

3. ASSET LOADING FAILURES (15% likelihood)
   ├─ Fonts failing to load (Google Fonts CDN down)
   ├─ Missing public assets (favicon.ico, images)
   ├─ CSS file 404 errors
   ├─ Network request failures
   └─ NEXT_DISABLE_FONT_DOWNLOADS without fallback

4. LAYOUT/CONTAINER ISSUES (10% likelihood)
   ├─ Flexbox/Grid misconfiguration
   ├─ Content positioned off-screen
   ├─ Overflow hidden hiding content
   ├─ Z-index issues (content behind invisible overlay)
   └─ Missing viewport meta tags

5. NEXT.JS 16 SPECIFIC (5% likelihood)
   ├─ Build script failures
   ├─ Async params not properly awaited
   ├─ React Compiler issues
   └─ Feature flag misconfigurations

Step 1: Open Browser DevTools (F12)
  ├─ Console Tab: Look for RED ERROR MESSAGES
  │  ├─ "Cannot find module" → Missing import
  │  ├─ "Hydration mismatch" → Server/client difference
  │  └─ "is not defined" → Variable reference error
  │
  ├─ Network Tab: Check assets loaded
  │  ├─ CSS files: Should load (not 404), size > 100KB
  │  ├─ Fonts: Check Google Fonts loaded
  │  └─ Images: Any 404 errors?
  │
  └─ Elements Tab: Verify DOM
     ├─ Does <html> tag exist?
     ├─ Does <body> tag exist with dimensions?
     └─ Does <main> tag exist?

Step 2: Check CSS Files
  bash: ls -lah .next/static/css/
  ├─ Should show 1+ files
  ├─ Each file > 100KB (unless empty project)
  └─ If missing: CSS build failed

Step 3: Run Diagnostic
  bash: node scripts/diagnose-black-screen.mjs
  ├─ Checks CSS imports
  ├─ Verifies layout files
  ├─ Confirms error handling
  └─ Validates dependencies

  QUICK REFERENCE: THE THREE BROWSER CHECKS
═══════════════════════════════════════════════════════════════════════════════

CONSOLE (F12 → Console)
  ├─ Any RED error messages?
  │  └─ YES → Copy and search codebase for error text
  └─ NO → Issue is CSS or rendering (not JavaScript)

NETWORK (F12 → Network → Reload)
  ├─ CSS file loads (not 404)?
  │  ├─ YES, size > 0 → CSS loaded
  │  ├─ NO (404) → CSS build failed
  │  └─ YES, 0 bytes → CSS empty (build error)
  ├─ Fonts loading?
  │  ├─ NO (404) → Use system fonts
  │  └─ YES → Font loading OK
  └─ Other assets?
     └─ Any RED icons? → Those files missing

ELEMENTS (F12 → Elements)
  ├─ <html> tag visible?
  │  └─ YES → DOM rendered
  │  └─ NO → JavaScript error prevented render
  ├─ <body> tag visible with dimensions?
  │  └─ YES → Layout exists
  │  └─ NO → CSS not applying
  └─ <main id="main-content">?
     └─ YES → Page structure correct
     └─ NO → Layout issue

═══════════════════════════════════════════════════════════════════════════════
  GOLDEN RULES
═══════════════════════════════════════════════════════════════════════════════

1. EVERY ERROR SHOWS IN THE BROWSER
   └─ F12 → Console will always show what's wrong
   └─ If nothing in console, issue is CSS loading

2. BLACK SCREENS ARE NEVER MYSTERIOUS
   └─ CSS not loading → Network tab shows 404
   └─ JavaScript error → Console shows red error
   └─ Layout issue → Elements inspector shows 0 dimensions
   └─ Async failure → Console shows error from failed function

3. START WITH BROWSER DEVTOOLS
   └─ 90% of issues visible in F12
   └─ Console, Network, and Elements tabs
   └─ Check these FIRST before changing code

4. BUILD FROM SCRATCH IF STUCK
   bash: bun run clean:build-artifacts && bun run build
   └─ Fixes 40% of issues
   └─ Run this before trying anything else

5. EVERY PAGE STATE NEEDS VISIBLE CONTENT
   └─ Loading? Show spinner
   └─ Error? Show error message
   └─ Empty? Show placeholder
   └─ Never show blank screen
