## Design Decisions

1. **Server-side origin**: `isAdmin` is computed server-side via `isAdminUser(user)` in the dashboard layout, then propagated through `DashboardProviders` → `DataProvider` → `isPlusUser()`.
2. **Following existing pattern**: `isAdmin` was added to `DashboardUiState` and `uiStateValue` following the exact same pattern as `isSharedView`.
3. **Default = false**: `isAdmin` defaults to `false` to preserve existing behavior for non-admin users.
4. **Bypass is FIRST**: The admin check in `isPlusUser()` is the very first line, before any subscription store lookups.
